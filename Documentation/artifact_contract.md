# Artifact Contract

## Ownership
- Module 1 owns `train.pkl`, `val_model.pkl`, `val_policy.pkl`, `test.pkl`, `app_test_adv.pkl`, `income_cap.joblib`, and `processed_artifact_manifest.json` under `data/processed/`.
- Module 2 owns FULL and REDUCED builder joblibs plus matching builder manifest JSON files under the active artifact directory.
- Module 3 owns FULL and REDUCED model, calibrator, and explainer artifacts plus `reproducibility_report.json`, and writes `model_fairness_audit_passed.joblib` as a placeholder `False`.
- Module 4 owns the final overwrite of `model_fairness_audit_passed.joblib` and its fairness/explainability outputs.
- Module 5 is read-only in real mode and must not write artifacts.

## Processed Manifest Contract
Module 1 writes `data/processed/processed_artifact_manifest.json` with these required fields:
- `manifest_version`
- `processed_manifest_fingerprint`
- `git_commit` when available
- `application_train_cleaned_rows`
- `income_cap`
- `split_fingerprints`
- `split_schema_hashes`
- `split_summary`
- `duplicate_summary`
- `adversarial_summary`

## Builder Manifest Contract
Explicit Module 2 persistence writes these pairs into the active artifact directory:
- `full_feature_builder.joblib` + `full_feature_builder.manifest.json`
- `reduced_feature_builder.joblib` + `reduced_feature_builder.manifest.json`

Each builder manifest must include:
- `builder_tier`
- `processed_manifest_fingerprint`
- `fit_row_count`
- `fit_split_name`
- `dataset_fingerprint`
- `encoded_column_count`
- `encoded_column_schema_hash`
- `pre_model_column_schema_hash`
- `rare_map_schema_hash`
- `aggregate_contract_version`

## Runtime Loader Contract
- `src/builder_artifacts.py` is the only legal builder load/validate path.
- No module outside `src/builder_artifacts.py` may directly `joblib.load()` builder artifacts.
- `strict_artifacts=True` requires processed manifest lineage plus matching builder manifests.
- `strict_artifacts=False` may skip lineage matching when manifests are absent, but it must still reject non-builders and wrong-tier builders.

## Frozen Runtime Input Set
- Real API startup defaults to `data/processed/` and `artifacts/`.
- The canonical processed runtime input is `data/processed/processed_artifact_manifest.json`.
- The canonical builder runtime inputs are the top-level FULL and REDUCED builder joblib and manifest files under `artifacts/`.
- The canonical scoring runtime inputs are the top-level FULL and REDUCED model, calibrator, explainer, and fairness files under `artifacts/`.
- `artifacts/reproducibility_report.json` is metadata only; startup may proceed without it.
- Nested experiment folders under `artifacts/` are offline-only and must not be treated as runtime inputs.

## Stale Artifact Policy
- Any checked-in artifact that the current source cannot regenerate is stale.
- Stale artifacts must be quarantined, marked obsolete, or removed from default runtime paths.
- Default runtime paths must point only to contract-compliant artifacts generated by current source.
- Alternate split-mode outputs such as `artifacts/random_stratified_reduced/` and offline research outputs such as `artifacts/reduced_thin_blend/` are preserved evidence, not default runtime paths.
